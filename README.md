# regalium-os/homebrew-tap

Homebrew formulae for RegaliumOS tools.

```sh
brew install regalium-os/tap/bacnet-probe
```

| Formula | What |
| --- | --- |
| [`bacnet-probe`](Formula/bacnet-probe.rb) | Discover, browse, watch and export BACnet/IP devices: a TUI and a scriptable CLI. Source: [regalium-os/bacnet-rs](https://github.com/regalium-os/bacnet-rs/tree/main/tools/bacnet-probe) |

Formulae are generated by each project's release workflow
(`tools/bacnet-probe/dist/formula.sh` for `bacnet-probe`) from the archives it
publishes, so a formula always matches a GitHub release byte for byte. Do not
edit them by hand; re-run the release instead.
